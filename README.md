# SWYNEX Exploratory Data Analysis

## Project Overview

This project is part of Task 2 – Exploratory Data Analysis (EDA) for my Data Analyst Internship at SWYNEX Technologies.

The analysis uses the cleaned Netflix Movies and TV Shows dataset from Task 1.

## Dataset

- Dataset: Netflix Movies and TV Shows
- Total Records: 8,807
- Total Columns: 12
- Source: Kaggle Netflix Titles Dataset
- Tools Used: Python, Pandas, Matplotlib, Google Colab

## Objectives

- Explore the cleaned dataset
- Calculate important statistics
- Identify trends and patterns
- Analyze content types, countries, ratings and genres
- Create meaningful visualizations
- Extract useful insights from the data

## Analysis Performed

The following analyses were performed:

1. Movies vs TV Shows
2. Netflix Titles by Release Year
3. Top 10 Countries
4. Content Rating Distribution
5. Top 10 Genres

## Key Insights

### 1. Movies vs TV Shows

Movies dominate the dataset with **6,131 titles (69.6%)**, while TV Shows account for **2,676 titles (30.4%)**.

### 2. Release Year Trend

The year **2018** has the highest number of titles in the dataset, with **1,147 titles**.

### 3. Top Country

The **United States** is the country associated with the highest number of titles, with **3,686 titles**.

### 4. Content Rating

**TV-MA** is the most common content rating, with **3,208 titles**.

### 5. Top Genre

**International Movies** is the most common genre/category, appearing in **2,752 titles**.

## Conclusion

The exploratory analysis shows that Netflix's catalog contains considerably more Movies than TV Shows. The United States contributes the largest number of titles, while TV-MA is the most common content rating. The analysis also highlights release-year trends and the popularity of different content categories.
